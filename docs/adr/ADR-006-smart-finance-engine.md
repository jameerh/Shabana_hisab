# ADR-006: Smart Finance Engine

## Context
Features like budgets, EMI trackers, and recurring transactions need a cohesive engine rather than existing as disjointed screens.

## Decision
Group all proactive financial tools into a "Smart Finance Engine" that registers capabilities into the Recommendation Pipeline.

## Alternatives Considered
Building isolated screens for every feature.

## Consequences
Financial insights will proactively surface on the dashboard and activity feed without the user having to dig into specific modules.
